This folder contains two utilities:

1. Flash_Program_EHP_SOM - Utility for flashing the generated loader file onto the board
2. init_code_sharc_fx - Utility for initialization sequence required to create the flash-ready loader files.
3. bootloader_sharcfx - Utility to flash all the four applications denoiser, kws, genre_identification, urbansound classification to the board and provide user the option to choose and run any one among the four using push buttons.
