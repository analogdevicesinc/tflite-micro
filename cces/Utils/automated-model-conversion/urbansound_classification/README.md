This folder contains scripts for downloading and generating TensorFlow Lite Micro (TFLM) model files from publicly available prebuilt models [https://github.com/cetinsamet/music-genre-classification.git] for the genre_identification project. Since these models do not have a permissive license for direct redistribution, we provide scripts to obtain and convert them instead of sharing the model files.

Ensure to have python 3.10.x Any Stable Release like [this one](https://www.python.org/ftp/python/3.10.11/python-3.10.11.exe) and git installed and available in your system's PATH 

#### Windows
Run the `enable_long_paths.reg` file to add support for long paths in Windows.

Run the `convert_models.bat` file to generate the float and int8 quantized model files for genreID project.

#### Unix
Run the `run_in_bash.sh` file to generate the float and int8 quantized model files for urbansound_classification project.

The generated model files will be populated in the `cces\examples\urbansound_classification\common\model\`
Model files in `cces\examples\urbansound_classification\common\model\int8_urbansound_class_ID` is required to build and run the application. Absence of .cc and .h files in this folder will lead to build errors.

> **Important — INT8 weight reordering:** After the INT8 TFLite model is generated by `convert_model.py`,
> the script automatically runs `reorder_weights_fc_and_conv1x1.py` to reorder FC and Conv1x1
> weights into a blocked layout required by the SHARC-FX DSP SIMD kernels. The reordered model is
> then used to generate the TFLM C arrays. Do NOT skip or bypass this step — using a plain (non-reordered)
> INT8 model will produce incorrect inference results on the SHARC-FX target.
